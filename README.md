## 这是什么

一份**个人思考的记录与整理**，不是学术论文，也不是方法论。

它试图回答一个问题：**当直觉互相冲突时，按什么排序？**

例如下面这些真实的冲突，文档里都给了裁决方式：

| 两条原则打架时        | 怎么裁                             |
| -------------- | ------------------------------- |
| 课题分离 ↔ 共情与责任   | 看**行动的主语**。感受可以很深，行动必须分清归属      |
| 拒绝外部认同 ↔ 接受反馈  | 看**能否翻译成动作**。能翻译的是信息，不能的是身份评价   |
| 行动先于动机 ↔ 想清楚再动 | 看**可逆性**。可逆 → 先动；不可逆 → 先想       |
| 接纳现状 ↔ 改变现状    | 看**可改变性**。对可改变的认命、对不可改变的较劲，是两种病 |
| 提高转化率 ↔ 允许自己承受 | 看**这次冲击有没有击穿你的准备**。接得住的建能力，已击穿的只承受 |
| 换环境 ↔ 深耕积累     | 看**问题出在环境，还是出在你带在身上的解释框架**        |

## 它从哪开始：命与运

开篇不是技巧，是一张地图。作者提出的模型把四件事分开：

- **命格** —— 你在某一刻的完整状态（不是一个标签，是一个时间切片）
- **命理** —— 命格上的坐标轴：性别、年龄、样貌、身体素质、家庭、职业、伴侣、三观……
- **命** —— 状态的整条轨迹：过去 + 现在 + 未来趋势
- **运** —— 外生输入：无法从你当前状态和规则里推出来的那股力量

写成一条式子：**G(t+1) = F( G(t), U(t) )**。G 是命格，U 是运，F 是"接下来会怎样"的规则。

这条式子只干一件事：**把"命"和"运"从两个名词，变成两个位置。** 凡是能从你当前状态算出来的，都是命的展开；算不出来的，才叫运。

由它推出六条可操作原则，包括：命是慢变量、运是快变量；你控制不了运，但能决定它的**转化率**；三观是唯一能**改写规则本身**的变量；你改不了单次运气，但可以换自己在哪张桌子上掷骰子。

> 这一层里有一条自我约束：**说「这是命」必须付代价。** 一个能解释一切的说法，等于什么都没解释。所以运只能在**事前**被有意义地谈论。

```
Part I   作者已说出的四条          ← 文档的原点，其余都是延伸
Layer 0  命运层 · 什么能改，什么不能改  6 条
Layer A  资源层 · 能量与注意力      4 条
Layer B  边界层 · 你与他人          4 条
Layer C  本体层 · 情绪与自我        5 条
Layer D  认知层 · 判断与决策        6 条
Layer E  行动层 · 时间与执行        5 条
Layer F  意义层 · 存在与方向        3 条
Meta     元层 · 关于这套逻辑本身     4 条
仲裁表   11 组常见原则冲突的裁决方式
```

**每条都是统一结构**，不写"要乐观""要专注"这种无法执行的话：

| 字段     | 回答的问题            |
| ------ | ---------------- |
| **原式** | 一句话怎么表述          |
| **机制** | 为什么它成立（因果链，不是断言） |
| **边界** | 什么时候它会失效、会被滥用    |
| **动作** | 具体做什么，通常带一个自问句   |

其中「边界」是这份文档和鸡汤的分界线。比如"你在寻求谁的认同，就是在向谁赋权"这条，滥用会变成拒绝一切反馈——所以它明确写了**如何区分信息性反馈与身份性认可**。

## 如果只记 7 条

41 条会稀释熟练度。压力时刻你只有几秒钟，能想起来的只有最熟的三五条。**先给这 7 条排序——那个顺序就是你的价值观。**

1. **精力要分配，不是靠意志** —— 增源 / 节流 / 按节律调度
2. **你在思考谁的问题，就是在参与谁的因果** —— 停止替别人背负因果
3. **你在寻求谁的认同，就是在向谁赋权** —— 把裁判权收回来
4. **情绪可堪破** —— 它是对解释的反应，不是对事实的反应
5. **行动先于动机** —— 等待动力是效率最高的拖延
6. **系统 > 目标** —— 目标定方向，系统出结果
7. **控制二分法** —— 只在「我能控制的」那一栏花时间

## 这套东西基于什么（以及不基于什么）

它**不是**基于统计学的实证研究。仓库里没有数据集，也没有做元分析。

文档里的主张其实是三类，混在一起但性质完全不同：

| 类型        | 例子                     | 怎么对待它                 |
| --------- | ---------------------- | --------------------- |
| **机制演绎**  | 蔡格尼克效应、注意力残留、环境与认知负荷   | 可以查文献、可以被证伪，**请以原始文献为准** |
| **第一人称试错** | 「同时改多条原则等于没改」          | N=1 的观察，可复制但不可推广        |
| **价值承诺**  | 「数据胜过道理」「允许自己只是承受」     | 不可证伪，是**选择**而非事实        |

需要单独说明的是第三类。这类主张大多是 **排序主张**，不是事实主张——它说的不是"世界是什么样"，而是"当两条都成立时，我先按哪条"。**从「是」推不出「应该」**，所以这一部分不是被证明出来的，是被选择出来的。

这也是为什么整份文档坚持给每条写明**边界**：一份不说自己什么时候失效的清单，无论包装成什么，都只是鸡汤。
